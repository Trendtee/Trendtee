## Hi, I'm Trendtee, the creator behind ViralClipzTV 👋

I make short-form animated videos as **ViralClipzTV**, and I build the open-source tools I wish existed for that work: **programmatic 2D animation with Remotion and TypeScript**.

My focus is the part of character animation that usually breaks: hands touching things. A character reaches for a mug, grips it, carries it and puts it down, and the object should never float, snap or slide through the fingers.

### 🎯 What I'm working on

- **Reliable character rigging for code-driven video:** two-bone IK, jointed fingers and grip poses for everyday objects.
- **Animation quality control:** catching teleporting props, slipping grips and impossible poses in tests, *before* rendering.
- **Remotion + TypeScript workflows:** frame-deterministic helpers that work in parallel renders.

**Next up:** an npm release of the rig toolkit, more grip presets, and a small open-source QC tool for rendered animation.
